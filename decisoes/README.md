# Decisões (ADRs)

Aqui ficam **Architecture Decision Records** numerados.

## Convenção

- Nome do arquivo: `NNNN-titulo-curto.md` (ex.: `0001-filas-para-jobs-async.md`).
- Use o template: [`templates/adr.md`](../templates/adr.md).
- Numere em ordem crescente (`0001`, `0002`, …).
- Texto em pt-BR, genérico, sem dados de empresa/cliente.

## Conteúdo mínimo de cada ADR

1. Contexto  
2. Opções consideradas  
3. Decisão  
4. Consequências  

## Status comuns

`Proposta` · `Aceita` · `Deprecated` · `Substituída por ADR NNNN`

Quando uma decisão nascer só no chat, registre aqui antes que suma.
