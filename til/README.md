# TIL — Today I Learned

Aprendizados curtos e reutilizáveis. Sem narrativa longa e sem dados de empresa/cliente.

## Formato

- Um arquivo por aprendizado.
- Nome: `AAAA-MM-DD-assunto.md` (ex.: `2026-10-10-rebase-vs-merge.md`).
- No máximo **5 linhas** de conteúdo útil (além do título, se houver).
- Português (pt-BR). Genérico o bastante para repo público.

## Como adicionar

1. Crie o arquivo com a data do aprendizado.
2. Escreva o insight em poucas linhas (o que, por que importa, como lembrar).
3. Opcional: linke no README da raiz se quiser destaque.
